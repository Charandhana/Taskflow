# 🚀 TaskFlow – Project & Task Management System

TaskFlow is a web-based project and task management application developed using Python and Django. It helps users manage projects, organize tasks, collaborate with team members, and monitor project progress through a simple and professional dashboard.

## ✨ Features

- 👤 User Registration and Login
- 📁 Create and Manage Projects
- 👥 Add Team Members
- 📝 Create, Edit, and Delete Tasks
- 📌 Assign Tasks to Team Members
- 📊 Track Project Progress
- 🔄 Kanban Board (To Do, In Progress, Completed)
- 💬 Task Comments and Team Communication
- 🎨 Modern Dark Theme UI

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite

## 🎯 Project Objective

The main objective of TaskFlow is to simplify project management by providing a centralized platform where teams can plan projects, assign responsibilities, track task completion, and improve collaboration.
